Это локальное веб приложение для создания или импорта задач на Polygon.

## Запуск

Если у вас портативная версия, достаточно запустить QW_Poly_Portable\Start_QW_Poly.bat , дополнительные установки не потребуются.

Все шаги ниже предназначены для варианта с установкой открытого кода.

Для запуска проекта локально вам понадобится установленная среда выполнения [Node.js](https://nodejs.org/) (рекомендуется версия LTS 18 или 20).

### Шаги для запуска:

1. **Перейдите в папку проекта** и откройте терминал.
2. **Установите зависимости** (пакет сборщика Vite):
   ```bash
   npm install
   ```
3. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```
4. **Откройте приложение**:
   После запуска в терминале появится локальный адрес.
   ```
   http://localhost:5173/
   ```

> **Локальное проксирование API:**
> Для обхода ограничений CORS при работе с API Polygon, в конфигурационном файле `vite.config.js` настроено локальное проксирование. Все запросы к `/api`, `/p*` (страницы задач) и `/c/` (конкурсы) автоматически перенаправляются на официальный сервер `https://polygon.codeforces.com`.
